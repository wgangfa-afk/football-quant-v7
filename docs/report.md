# 报告契约

中文 Word 与短摘要使用同一个冻结报告 DTO；报告层不重新定价或评级。报告包含生成时间、北京时间窗口、数据来源和时间、发现数量与完整度、推荐摘要、全扫描表、主市场/角球/罚牌候选池、深度分析、低置信方向、PASS 原因、模型/市场/去水概率、理论/当前赔率、原始/风险调整 EV、风险、缺失冲突与方法说明。

深度分析以普通中文说明支持理由、反对理由、人员/战术/赛程和可能推翻判断的风险；概率不称为保证。来源链接可点击并标示来源名、采集时间，原始数据附于研究包。

所有发现赛事保留；进行中/结束/窗口外赛事清楚排除于投注候选。若晚于开赛完成报告，即使采集时未开赛也不能列为可执行赛前推荐。报告不等待二次采集；使用生成时间剔除已开赛的可执行推荐。

必须标识测试报告与真实报告，真实报告拒绝 test 数据。普通 pytest 只验证 Word 结构、数据一致性、超链接；交付必须另外 render_docx.py → 打开全部 PNG → 修正 → 重渲染。检查中文字体、分页、空白页、表格边界及数值格式。不以 XML 检查冒充视觉检查。
