# 市场与显示规范

支持全场常规时间（含补时，不含加时/点球）的 1X2、亚洲让球、亚洲大小球、总进球准确数、BTTS；辅助支持角球大小/让球、罚牌大小/让分。规则不明 PASS；不得混合半场、全场或不同罚牌计分规则。

1X2 三向，BTTS 两向，总进球准确数必须包括穷尽剩余结果的尾部档（如 7+）。完整同时点市场才去水；不完整市场仍保存报价，但市场去水概率不可用，不能正式推荐。

亚洲盘、角球和罚牌报告为线 + 香港水位；其他为欧洲十进制赔率。保留原始值、原始格式及十进制计算值。HK h>0 → d=1+h；EU d>1；MY 0<|m|≤1，正数 d=1+m，负数 d=1+1/|m|；ID |i|≥1，正数 d=1+i，负数 d=1+1/|i|。拒绝零、bool、NaN、无穷及非法范围。

主队让球以主队进球差 + 主队盘口结算；客队盘口从客队角度计算。大小球以总数 - 线（大）、线 - 总数（小）结算。四分之一线拆成相邻半球线等额两腿。赢/半赢/走/半输/输都必须计入 EV。

角球模型只处理角球计数；牌模型只处理明确一致的牌数/罚牌积分口径。裁判缺失必须披露，口径不明或历史统计与盘口口径不一致 PASS。辅助模型未经校准最多 C；成熟验证后需独立审查提升。
