# 产品契约

Football Quant V7 是独立的新项目。仅在本仓库开发；禁止读取或复用废弃项目的代码、数据库、测试或架构。不建立 A/B 分区。

用户手动提供截止时间；起点为任务启动时的时区感知时间。默认北京时间，赛前窗口为 (启动时间, 截止时间]。同一次研究只采集一次，不等待首发或临场刷新。发现赛事均保留于扫描表；覆盖范围仅限实际公开发现且可核验的赛事，不声称穷尽全球。

公开盘口可得的全球赛事均可纳入，包括女足、青年、杯赛、国家队、地区及低级别联赛。候选深入分析，其余记录具体 PASS 原因。滚球仅在明确请求后单独运行，不能混入赛前报告。V1 不提供滚球运行入口。

第一阶段：网页证据 → 核验 → 多模型概率 → 多市场定价 → S/A/B/C/PASS → 中文摘要及 Word。缺少官方首发仅披露风险，不构成评级扣分。已确认核心缺阵、轮换必须纳入有依据的情景调整或阻止确定性模型推荐。

不开发：球员市场、自动串关、定时任务、真实账户和下注、模拟账本。真实报告由用户验收后，才另行实现 ¥10,000 模拟资金、半 Kelly、3%/5%/12% 风险上限与结算复盘。不得提前预建数据库或账本抽象。

M0 规范和检查；M1 固定证据端到端；M2 公开网页研究；M3 主市场；M4 独立角球罚牌；M5 用户给定截止时间的真实报告、全量测试和渲染检查，随后创建审查 PR 并停止等待验收，不合并。

所有阶段独立提交；main 为默认分支，开发分支 codex/football-quant-v7-mvp。不重写公共历史、不强推。验收需要真实研究而非测试样例，无真实报告不得宣称第一阶段已完成。
