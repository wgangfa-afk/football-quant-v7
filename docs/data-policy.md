# 数据来源与核验政策

仅允许 Codex 网页搜索、正常公开网页、官方信息及合法 HTML/文本/CSV/JSON-LD 快照。禁止所有数据 API（含付费、隐藏接口）、API key、保存凭据、Cookie、token、Authorization、高频采集和任何访问限制绕过。GitHub 工程操作不属于足球数据源。

登录页面必须先得到用户对该特定网站的授权，通过受支持的浏览器登录能力操作；不得要求密码出现在聊天或代码。遇到验证码、登录限制、付费墙即停止该来源，记录未覆盖原因。不从浏览器后端网络请求提取隐藏接口。

不设固定主站。选择来源应按可访问性、采集和页面更新时间、完整市场、明确运营者、多源一致性和过期风险评估。同源转载不算独立验证。网页未提供时间就留空，不将采集时间伪装成盘口更新时间。

每条事实引用不可变证据：source_url、source_name、retrieved_at_utc、observed_at_utc（可空）、published_at_utc（可空）、source_type、content_hash（SHA256 原始快照字节）、extraction_method、validation_status。所有时间带时区并规范为 UTC。快照与提取值一同保留，原始赔率不得覆盖。

同一事实尽量交叉核验。冲突保留所有断言及来源，不平均不同盘口，不静默选一条；冲突降低置信度，关键事实未解决则 PASS。盘口必须区分比赛、博彩公司、市场、时段、盘口线、选择、计数/结算规则及观察时间。不同时间的报价属于变化，不能误报成同时冲突。

数据缺失使用空值和具体理由，绝不凭记忆填写实时赛程、赔率、伤停。不能根据市场赔率反推 λ 后冒充独立足球模型。研究包必须明确 test/live，真实报告拒绝任何测试证据。普通 pytest 无网络，固定文件与明确标为合成的数学 fixture 仅证明链路，不证明实战预测能力。
