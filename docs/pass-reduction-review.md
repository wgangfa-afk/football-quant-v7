## 最新报告问题

`scripts/build_m5_report.py` 是一次性硬编码文档，未调用研究包加载、证据验证、模型、定价或评级。它把“没有完整市场”直接写成“不能计算 EV”，与 `pricing.price()` 本来支持 `market_probability=None` 的事实矛盾。脚本已显式停用；真实报告改由 `football_quant.application analyze` 生成。

## 修改前后行为

| 场景 | 修改前 | 修改后 |
|---|---|---|
| 单项普通赔率 + 独立模型概率，其他赔率缺失 | EV 已算出但强制 PASS | EV 保留；去水概率为空；评级按原评分规则运行 |
| 有事实、无赔率 | 只有 missing/PASS 文本 | 输出定性方向、支持/反向证据、不确定性；概率与 EV 留空 |
| xG 缺失、基线充分 | 可算但模型来源不清 | 继续用进失球基线，并明确模型来源 |
| 模型输入不足 | 无 λ，多个概念混在 PASS | 无 λ/概率；列出具体缺失字段；分析能力单列 |
| 赔率无效或规则不支持 | 先计算价格、后以原因 PASS | 对应报价不计算 EV；其他市场不受牵连 |
| 辅助市场缺数据 | 整场 missing 混入辅助错误 | 主市场照常计算；对应辅助候选单独拒绝 |
| 负 EV | 可保留但仍受完整市场门禁 | 数值原样保留；`原始EV非正` 与决策结果分别展示 |
